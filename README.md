# CS114 Course Project — Student Depression Classification

Đây là đồ án nhóm của môn **CS114 – Machine Learning**.

Project xây dựng mô hình phân loại nhị phân nhằm dự đoán nhãn `Depression`
từ dữ liệu khảo sát về học tập, sinh hoạt và sức khỏe tinh thần của sinh viên.

## Pipeline

- Xử lý missing values, categorical features và chuẩn hóa dữ liệu.
- Chia dữ liệu thành tập train và holdout theo tỷ lệ 80/20.
- Huấn luyện và so sánh Logistic Regression, SVM và Decision Tree.
- Đánh giá bằng Accuracy, Precision, Recall và F1-score.
