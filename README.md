# CS114 Course Project — Student Depression Classification

The project builds a binary classification model to predict the `Depression` label using survey data on students' academics, lifestyle, and mental health.

## Pipeline

* Handled missing values, processed categorical features, and standardized the data.
* Split the dataset into training and holdout sets at an 80/20 ratio.
* Trained and compared Logistic Regression, SVM, and Decision Tree models.
* Evaluated performance using Accuracy, Precision, Recall, and F1-score.
